# Taxonomy: capabilities

Use these ids (see `graph/nodes.yaml`). Do not freelance labels.

| Id | Name | Meaning |
|----|------|---------|
| `event-models` | Event models | Customer-owned event schemas; evolve without classical migrations |
| `campaigns` | Campaigns | Executable programs (Draft/Live), not config rows |
| `journeys` | Journeys | Stateful graphs of program steps |
| `rules-engine` | Rules engine | Declarative, polymorphic evaluation over symbols |
| `outcomes` | Outcomes | Points, tiers, tags, notifications, workflow, other pluggable results |
| `campaign-agent` | Campaign agent | Authors programs against the same APIs the engine runs |
| `mcp-api` | MCP / HTTP API | Machine and human contract for the runtime |
